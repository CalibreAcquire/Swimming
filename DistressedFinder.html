No free public feed exists for this signal. Individual repossession/receivership cases (county court possession orders, mortgagee-in-possession sales) are not published as open data or bulk API in England & Wales. The reliable public proxy is specialist property auction catalogues, which routinely flag lots as "in possession", "receivership" or "mortgagee sale". This tab is a curated directory + workflow, not a live scraper — scraping these commercial catalogue sites would likely breach their terms of use.

How it works: The Gazette publishes free, live Deceased Estates notices (Trustee Act 1925, s.27) — personal representatives inviting creditor/beneficiary claims before distributing an estate. These name the deceased, date of death, last known address and the solicitor/executor handling the estate. It is a genuine live signal, but the notice itself rarely confirms a property is still held — treat every result as a lead to verify, not a confirmed vacant property.
What isn't available: HM Courts & Tribunals' probate register (probatesearch.service.gov.uk) only supports one-name-at-a-time lookups once you already have a name — it's a verification tool, not a discovery feed. There is no free bulk "probate + still owns a house" dataset in England & Wales; some commercial data providers sell curated probate-lead lists if you need volume beyond what Gazette notices surface.
